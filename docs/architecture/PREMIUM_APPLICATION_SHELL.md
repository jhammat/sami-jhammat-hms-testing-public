# WonFlow Premium Application Shell

## Document Status

Task: WF-068  
Area: Shared Frontend Foundation  
Status: Premium shell baseline  
Scope: All WonFlow portals and workflows

## Purpose

The Premium Application Shell provides the shared navigation and workspace
structure for every WonFlow interface.

## Main Components

The shell contains:

- WonFlow brand identity
- Desktop navigation sidebar
- Compact sidebar mode
- Mobile navigation drawer
- Route-aware active states
- Sticky workspace header
- Workspace identification
- Global navigation search
- Demonstration-status indicator
- User and branch context
- Shared content container

## Navigation Groups

### Hospital Operations

Includes:

- Operations Overview
- Patient Directory
- Register Patient
- Appointments
- Book Appointment
- Live Patient Queue
- Billing Counter

### Clinical Workspace

Includes:

- Doctor Dashboard
- Patient Consultations
- Clinical encounters

### Diagnostic Services

Includes:

- Radiology

### Administration

Includes:

- Organization Administration
- Management Portal
- Platform Administration
- Patient Access
